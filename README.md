# JavaScript Trivia

A timed trivia game in two versions that share the same questions and rules:

- `trivia.js` is the command-line version (Node.js 18+, no dependencies). Run it with `node trivia.js`.
- `index.html`, `style.css` and `script.js` are the browser version. Open `index.html` in any browser.

## Rules

- 8 questions, shown one at a time.
- 15 seconds per question and 90 seconds for the whole game.
- Immediate feedback after each answer, then a score summary and a review at the end.
- Answer with a letter (A-D) or a number (1-4).

## JavaScript features used

- Functions and loops
- An array of question objects
- Array iteration methods: `map`, `filter`, `reduce`, `forEach`
- Timers: `setTimeout` (CLI) and `setInterval` (browser)
